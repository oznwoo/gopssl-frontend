# 커밋 메시지 컨벤션

## 형식

```
타입: 제목

본문 (생략 가능)
```

## 타입

| 타입       | 사용 시점                |
| ---------- | ------------------------ |
| `feat`     | 새로운 기능 추가         |
| `fix`      | 버그 수정                |
| `design`   | UI/스타일 변경           |
| `refactor` | 기능 변경 없는 코드 정리 |
| `chore`    | 설정, 패키지, 기타 잡무  |
| `docs`     | 문서 수정                |
| `remove`   | 파일 삭제                |

## 규칙

- 제목은 **간결하게** (50자 이하)
- 제목 끝에 **마침표 금지**
- 본문은 **왜** 바꿨는지 위주로 (생략 가능)

## 예시

```
feat: 카드 내역 목록 페이지 추가

fix: 로그인 후 리다이렉트 오류 수정

design: 대시보드 레이아웃 그리드로 변경

chore: pip 의존성 업데이트

remove: 미사용 SVG 에셋 삭제
```
